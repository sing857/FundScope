# FundScope

**看市场，也看自己。**

做这个项目的初衷很简单：我想弄清楚，一只基金过去究竟经历了什么。

净值曲线记录着涨跌，收益率呈现着结果，而波动与回撤则让那些容易被收益数字掩盖的风险逐渐显现出来。比起只看一段时间赚了多少，我更想知道，这份收益是在什么样的波动中取得的，又曾经承受过多大的下跌。

FundScope 是一个基于 Python 的金融数据分析项目，当前以公募基金历史表现分析为主要网页功能，同时包含一组独立的上市公司财务分析模块。项目仍在持续开发中，重点是把数据获取、指标计算和风险观察过程整理清楚，而不是提供投资结论。

## 当前功能

### 基金分析网页

输入基金代码后，可以获取历史净值并查看相关分析结果：

- 区间收益率、年化收益率
- 年化波动率、下行波动率
- 最大回撤及回撤区间、恢复情况
- 夏普比率、索提诺比率、卡玛比率
- 基金历史质量评分及评分构成
- 历史净值曲线、净值明细和数据质量信息

历史质量评分属于基于既定规则的初步评价，不代表未来表现，也不构成买入或卖出建议。

### 上市公司财务分析模块

项目还包含独立的企业财务分析代码，主要涉及：

- 财务报表数据获取与整理
- 历史财务数据和单季度指标构建
- 财务质量相关指标
- 营收、利润、利润率及现金流等趋势分析
- 基于规则的财务异常提示

**当前企业财务分析模块尚未集成到 Streamlit 网页界面。** 相关能力目前通过 Python 模块独立运行，不应将其理解为网页端已经提供完整的企业分析工作流。

### 尚未实现的功能

页面中的假设与反向检验区域目前只是功能入口，分析引擎尚未接入。项目不会将该入口产生的内容描述为已经完成的回测或智能分析结果。

## 技术栈

- Python：项目主要开发语言
- AKShare：获取公开金融数据
- Pandas、NumPy：数据整理与数值计算
- Streamlit：基金分析网页
- Matplotlib、Altair：数据可视化
- pytest：自动化测试

## 环境与安装

项目当前在 Windows 环境、Python 3.14.3 下完成测试。其他 Python 版本及操作系统尚未全面验证。

建议在项目目录中创建独立虚拟环境：

```powershell
python -m venv .venv
```

激活虚拟环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

如果 PowerShell 的执行策略阻止激活脚本，也可以不激活环境，直接使用虚拟环境中的 Python 可执行文件运行后续命令。

安装运行依赖：

```powershell
python -m pip install -r requirements.txt
```

启动基金分析网页：

```powershell
python -m streamlit run app.py
```

启动成功后，在浏览器中打开终端显示的本地地址。

## 运行测试

安装开发依赖：

```powershell
python -m pip install -r requirements-dev.txt
```

运行全部自动化测试：

```powershell
python -m pytest -v
```

当前项目已有 **40 项自动化测试通过**。测试覆盖基金收益与风险指标、评分规则，以及企业异常提示规则和边界情况。测试通过表示这些测试所覆盖的逻辑符合预期，不代表所有数据源、市场情形或业务风险均已得到验证。

## 数据与计算说明

基金历史净值及相关公开金融数据通过 AKShare 等数据接口获取。数据接口的可用性取决于网络环境和上游服务，数据可能存在延迟、缺失或口径差异。

当前基金分析使用项目所获取的净值数据进行计算。基金分红、复权方式、数据完整性和年化计算口径等因素都可能影响结果。使用分析结果前，应结合原始数据和基金产品资料进行核对。

企业财务分析依赖公开财务报表数据。财务指标和异常提示属于规则化分析工具，不能替代对企业经营模式、行业特征、会计政策及其他定性因素的全面调查。通用规则也不一定适用于银行、保险、证券等金融机构。

## 后续方向

项目会优先完善现有数据校验、计算口径和分析逻辑，再逐步推进基金比较、业绩基准及更系统的风险分析。企业分析模块也需要进一步验证，并在条件成熟后再考虑接入网页界面。
