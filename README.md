FundScope



看市场，也看自己。



做这个项目的初衷很简单：我想弄清楚，一只基金过去究竟经历了什么。



净值曲线记录着涨跌，收益率呈现着结果，而波动与回撤则让那些容易被收益数字掩盖的风险逐渐显现出来。比起只看一段时间赚了多少，我更想知道，这份收益是在什么样的波动中取得的，又曾经承受过多大的下跌。



FundScope 是一个基于 Python 的公募基金分析工具。目前，它能够获取基金历史净值，计算几项常见的收益与风险指标，并将结果呈现在一个简单的网页界面中。



它还很初级，但至少是一个可以实际运行、持续改进的开始。

目前能做什么



输入基金代码后，可以查看对应基金的历史净值，并计算以下指标：



&#x20;区间收益率

&#x20;年化收益率

&#x20;年化波动率

&#x20;最大回撤

&#x20;夏普比率



网页同时提供历史净值曲线和原始数据表格，方便观察基金在不同阶段的表现。



使用的工具



项目主要使用 Python 完成数据获取、整理和计算。



Pandas：处理历史净值数据

NumPy：完成数值计算

AKShare：获取公开金融数据

Streamlit：搭建交互式网页

`data\_fetcher.py` 负责获取和整理基金净值，`analyzer.py` 负责计算收益与风险指标，`app.py` 则将这些功能连接起来，提供一个可以直接使用的网页界面。



如何运行



建议使用 Python 3.12 或 3.13，并在项目目录中执行以下命令。



创建虚拟环境：



powershell

python -m venv .venv

...



激活环境：



powershell

.\\.venv\\Scripts\\Activate.ps1





安装依赖：



powershell

python -m pip install -r requirements.txt



启动网页：



powershell

python -m streamlit run app.py





启动成功后，在浏览器中打开终端显示的本地地址即可。



数据与计算



基金历史净值通过 AKShare 提供的数据接口获取。接口的可用性取决于网络环境及上游服务，数据获取失败时需要进一步检查。



当前版本使用单位净值进行基础分析。基金分红、复权方式、年化计算口径等因素都可能影响分析结果，相关计算仍有进一步完善的空间。



关于这个项目



我希望把它做成一个能够长期维护的小工具，而不是停留在一次性的代码练习上。



后续计划包括完善数据校验与收益计算逻辑，增加基金之间的横向比较，并逐步引入更合适的业绩基准和风险分析方法。



对于投资而言，数字能够帮助我们理解过去，却无法替我们确定未来。这个项目所做的，是尽可能把过去的表现整理清楚，让判断有据可依。
